# Chúc mừng 20/10 💗

Website chúc mừng 20/10 viết bằng HTML, CSS và JavaScript thuần.

## Cách sử dụng
- Mở `index.html` trong trình duyệt.
- Nhập tên ở màn hình đầu tiên rồi bấm **Mở lời chúc**.
- Xem lời chúc cá nhân hóa, hiệu ứng trái tim/cánh hoa và ảnh Polaroid ngẫu nhiên.
- Có thể chọn **Đổi tên người nhận** để thử tên khác.

Ảnh và font được tải từ Internet.
